# Sensitivity Analysis for 1D-CNN-Based Classifiers

This repository contains the Python implementation of the analytical framework presented in the paper **“A Sensitivity Analysis Framework for Uncertainty Propagation in 1D-CNN-Based Classifiers”**, intended for submission to **IEEE I²MTC 2027**.

The framework analyzes how uncertainty affecting input measurements propagates through a trained one-dimensional Convolutional Neural Network (1D-CNN). Input uncertainties are modeled as independent Gaussian random variables in the standardized feature space.

Three uncertainty-propagation methods are compared:

- **Conventional Monte Carlo simulation**, used as the numerical reference
- **Variance-matched Monte Carlo Dropout**, used as a faster stochastic approximation
- **First-order analytical linearization**, which estimates class probabilities without iterative simulations

The comparison provides the probability of assigning the input to each class, the expected sigmoid output, the execution time, and the speedup of the approximate methods relative to conventional Monte Carlo simulation.

---

## **Features**

- Trains a compact 1D-CNN for binary classification
- Uses the Wisconsin Diagnostic Breast Cancer dataset available in scikit-learn
- Selects and standardizes four measurement features
- Saves the trained CNN parameters and fitted input scaler
- Models input measurement uncertainty using Gaussian distributions
- Performs conventional Monte Carlo uncertainty propagation
- Computes an equivalent dropout probability from local CNN sensitivity
- Performs optimized Monte Carlo Dropout by reusing the convolutional features
- Propagates uncertainty analytically using first-order linearization
- Compares class probabilities, expected sigmoid outputs, execution times, and speedups
- Supports CPU and CUDA execution for the comparison script

## **Method Overview**

### **1. Train and Save the 1D-CNN**

The workflow starts with `cnn_training_save.py`.

The script:

- loads the Wisconsin Diagnostic Breast Cancer dataset;
- displays the 30 available features and the units defined in the script;
- selects `mean radius`, `mean texture`, `mean perimeter`, and `mean area`;
- reports the minimum, maximum, and range of the selected raw features;
- standardizes the inputs using `StandardScaler`;
- divides the data into training, validation, and test sets;
- trains a 1D-CNN using binary cross-entropy and the Adam optimizer;
- prints validation and test accuracy and confusion matrices;
- saves the model parameters and the fitted scaler.

The CNN architecture is:

```text
Input → Conv1D → ReLU → Flatten → Fully Connected Layer → Sigmoid
```

At the end of the training stage, the script prints:

```text
Model weights saved to 'model_weights.pt'.
Scaler saved to 'scaler.pkl'.
```

These files are required by `main.py` and must remain in the same directory as the Python scripts.

### **2. Conventional Monte Carlo Simulation**

`mc_classic.py` provides the numerical reference method.

For each iteration, the method:

- generates Gaussian noise in the standardized input space;
- adds the noise to the query sequence;
- propagates the perturbed input through the complete CNN;
- applies the classification threshold;
- records the assigned class and sigmoid output.

The final results are the empirical relative frequencies of Classes 0 and 1 and the mean sigmoid output.

### **3. Variance-Matched Monte Carlo Dropout**

`mc_dropout.py` computes a dropout probability that locally reproduces the logit variance caused by Gaussian input noise.

The method first evaluates the gradient of the pre-sigmoid logit with respect to the input. It then matches the local variance induced by the measurement noise with the variance produced by dropout at the output of the Conv1D/ReLU block.

To reduce computational cost, the convolutional representation is calculated only once. Each Monte Carlo iteration repeats only:

```text
Dropout → Fully Connected Layer → Sigmoid
```

This implementation is a locally variance-matched uncertainty-propagation method, rather than standard MC Dropout with an arbitrarily selected dropout rate.

### **4. Analytical Linearization**

`linearization.py` approximates the pre-sigmoid logit using a first-order Taylor expansion around the nominal query.

For independent Gaussian input noise with standard deviation \(\sigma_x\), the local logit variance is estimated as:

\[
\sigma_f^2 = \sigma_x^2
\left\lVert \nabla_{\mathbf{x}} f(\mathbf{x}) \right\rVert_2^2.
\]

The framework then computes:

- the analytical probabilities of assignment to Classes 0 and 1;
- an approximation of the expected sigmoid output;
- the result without a Monte Carlo sampling loop.

With the classification threshold set to 0.5, Class 1 corresponds to a positive logit. Its probability is obtained from the Gaussian cumulative distribution of the linearized logit.

### **5. Method Comparison**

`main.py` loads the saved weights and scaler, standardizes the selected raw query, and runs all three methods at the same operating point.

The output table reports:

- execution time;
- probability or relative frequency of Class 0;
- probability or relative frequency of Class 1;
- mean or approximated expected sigmoid output.

The script also reports the speedup of MC Dropout and analytical linearization relative to conventional Monte Carlo simulation.

## **Example Usage**

### **1. Install the Dependencies**

```bash
python -m pip install numpy torch scikit-learn joblib
```

### **2. Train the Model**

Run the training script first:

```bash
python cnn_training_save.py
```

Verify that the following files have been created:

```text
model_weights.pt
scaler.pkl
```

### **3. Configure the Query and Uncertainty**

The main settings are defined at the beginning of `main.py`:

```python
QUERY_VALUES = [19.07, 19.50, 91.40, 615.0]
NUMBER_ITERATIONS = 50000
CLASSIFICATION_THRESHOLD = 0.5
GAUSSIAN_NOISE_SIGMA = 0.1
INPUT_CLIP_RANGE = None
RANDOM_SEED = 42
```

`QUERY_VALUES` contains raw, non-standardized values in the same order used during training:

1. mean radius;
2. mean texture;
3. mean perimeter;
4. mean area.

`GAUSSIAN_NOISE_SIGMA` is defined in standardized input space. The saved scaler automatically transforms the raw query before the uncertainty analysis.

### **4. Run the Comparison**

```bash
python main.py
```

If the file has not yet been renamed, run:

```bash
python "main(1).py"
```

The script automatically loads `model_weights.pt` and `scaler.pkl`, executes the three uncertainty-propagation methods, and prints their results and computational performance.

## **Important Notes**

- Run `cnn_training_save.py` before `main.py`.
- Keep all Python modules, `model_weights.pt`, and `scaler.pkl` in the same directory.
- If the selected input features or their order are changed, retrain the model and regenerate both saved files.
- Keep `CLASSIFICATION_THRESHOLD = 0.5` when comparing the current analytical implementation with the Monte Carlo methods.
- `NUMBER_ITERATIONS` affects the accuracy and execution time of the two sampling methods, but not analytical linearization.
- The analytical model assumes independent, identically distributed Gaussian perturbations in standardized input space.
- Numerical results and execution times may vary with the hardware and software environment.
